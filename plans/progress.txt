## 2026-01-14 - bug-003

- Files changed: src/services/agent.ts
- **Learnings:**
  - A2A Message interface has `metadata` property directly on the message object
  - `sendMessageStream({ message, metadata })` is wrong - metadata must be in `message.metadata`
  - Correct: `sendMessageStream({ message })` where message includes `metadata` property
  - Existing e2e test validates correct metadata passing (agent needs LLM extension to respond)
